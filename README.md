# Lyrelog's Homebrew tap

```
brew install lyrelog/tap/lyrelog
```

`lyrelog` is the command-line tool for [Lyrelog](https://lyrelog.com): search events, follow them
live, read errors, sessions and people from your terminal. Docs: https://docs.lyrelog.com/cli

The cask in `Casks/` is written by each release of
[lyrelog/lyrelog-cli](https://github.com/lyrelog/lyrelog-cli).
